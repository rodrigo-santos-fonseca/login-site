# Sistema de Login e Cadastro - v1.1.0

Projeto desenvolvido para a atividade avaliativa de controle de versão com Git e GitHub.

## 🚀 Funcionalidades
- Página de login (`index.html`) com validação de campos via JavaScript (`script.js`).
- Painel principal (`dashboard.html`) com mensagem de boas-vindas.
- Formulário de cadastro de novos usuários (`cadastro.html`).

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
- Git / GitHub
